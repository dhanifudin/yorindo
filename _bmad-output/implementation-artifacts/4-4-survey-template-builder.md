# Story 4.4: Survey Template Builder

## Story
As an admin, I want to build a custom survey for each event using an add/remove/reorder question builder.

## Acceptance Criteria
- [x] Survey builder on event detail page
- [x] Add questions: text, single-choice, multiple-choice
- [x] Remove/reorder questions
- [x] PUT /api/events/:id/survey saves schema
- [x] GET /api/events/:id/survey loads existing schema
