# Story 4.3: Event Clone

## Story
As an admin, I want to clone an existing event with all config inherited, so I can set up recurring events quickly.

## Acceptance Criteria
- [x] "Clone Event" button on event detail page
- [x] Dialog opens to confirm clone
- [x] POST /api/events/:id/clone creates new draft event
- [x] Redirects to new event's detail page after clone
